# envfix Analytics Backend

A minimal FastAPI backend built to aggregate usage statistics and analytics for `envfix` across teams.

## Setup Instructions

1. **Start the Database**
   This project uses PostgreSQL. A `docker-compose.yml` file is provided for easy local setup.
   ```bash
   docker-compose up -d
   ```

2. **Install Dependencies**
   Ensure you have Python 3.10+ installed.
   ```bash
   pip install -r requirements.txt
   ```

3. **Run the Server**
   The application uses SQLAlchemy which will automatically create the tables on startup.
   ```bash
   uvicorn main:app --reload
   ```
   The API will be accessible at `http://localhost:8000`.

## API Usage Examples

### 1. Create a Team
Creates a new team and returns an auto-generated API Key.
```bash
curl -X POST http://localhost:8000/teams \
  -H "Content-Type: application/json" \
  -d '{"name": "Engineering Team Alpha"}'
```
*Make note of the `id` and `api_key` returned in the response.*

### 2. Log an Event
Logs a new usage event. Replace `YOUR_API_KEY` with the API key generated in Step 1.
```bash
curl -X POST http://localhost:8000/events \
  -H "Content-Type: application/json" \
  -H "X-API-Key: YOUR_API_KEY" \
  -d '{
    "error_type": "ZeroDivisionError",
    "provider_used": "groq",
    "was_cache_hit": false,
    "fix_applied": true,
    "fix_worked": true
  }'
```

### 3. Fetch Team Analytics
Fetches aggregated statistics for a given team ID. Replace `1` with your team ID and `YOUR_API_KEY` with your API key.
```bash
curl -X GET http://localhost:8000/teams/1/stats \
  -H "X-API-Key: YOUR_API_KEY"
```

## API Documentation
Interactive Swagger UI documentation is automatically generated by FastAPI and available at `http://localhost:8000/docs`.
